# HSK 3.0 1급 모의고사 제1회 듣기

참고 녹음 「一级试卷1-录音.mp3」의 진행 속도와 간격을 바탕으로 만든 연습 음원입니다. 표준 중국어 여성·남성 합성 음성을 사용했습니다. 예제 직후 문제 번호를 읽고, 예제와 문항 본문은 두 번씩 재생합니다.

참고 파일에서 약 13.6~13.9초의 긴 쉼 20개가 관찰됐습니다. 문항마다 13.73초의 응답 시간을 적용했습니다. 말하기 속도는 참고 녹음의 짧은 발화로 추정해 약 2.8한자/초를 목표로 조정했습니다.

- `hsk1-set01-examples.html`에서 전체 듣기, 부분별 듣기, 예제만 듣기를 선택할 수 있습니다.
- `hsk1-set01-examples/`에는 예제 음원 4개와 예제 포함 제1~4부분 음원 4개가 있습니다.
- `listening-script.json`에는 예제와 문항 대본이 있습니다.
- `build_audio.py`는 FFmpeg, NumPy, sherpa-onnx와 Kokoro 다국어 모델 `kokoro-multi-lang-v1_1`이 필요합니다. 모델 폴더를 인수로 전달해 실행합니다.
