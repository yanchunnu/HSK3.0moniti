# HSK 3.0 2급 제01회 듣기 음원 분석

참고음원 두 편을 16 kHz 모노로 디코딩했다. FFmpeg에서 −36 dB 미만이 0.45초 이상 이어지는 구간을 찾고 SenseVoice 중국어 전사에서 안내, 번호, 반복 구조를 대조했다. 아래 시각과 간격은 발화 경계 추정치다.

| --- | ---: | ---: |
| 파일 길이 | 20:30.72 | 20:30.46 |
| 第一部分 시작 | 00:50.57 | 00:50.64 |
| 第二部分 11–15번 전환 | 06:43.36 | 06:44.90 |
| 第三部分 시작 | 09:48.17 | 09:37.86 |
| 종료 안내 시작 | 20:26.36 | 20:26.10 |
| 25문항 풀이 무음 범위 | 13.67–14.15초 | 13.18–14.47초 |
| 부분별 풀이 무음 중앙값 | 13.98 / 13.88 / 13.84초 | 13.91 / 14.11 / 14.02초 |

두 녹음은 시험명과 회차, 인사·환영 세 번, 시험 구성 및 시작 안내로 열린다. 각 부분은 제목, 범위, 지시, 每题听两次, 예제 두 번, 시작 안내 순이다. 第二部分은 11번에서 사진 보기가 바뀌어 범위를 다시 읽는다. 번호는 문항당 한 번만 읽는다. 第一部分은 한 문장, 第二部分은 대화, 第三部分은 대화와 질문을 묶어 두 번 읽는다. 번호 뒤 쉼은 약 1.5–1.9초, 반복 사이는 대체로 2초대다.

기준 문제지에 표기된 듣기 시간은 약 17분이며 참고 녹음은 약 20분 30초다. 시험 구성표에는 책자 표기 시간을 썼다. 제01회 대본의 발화 길이 차이로 새 음원은 13분 59.43초다.

## 제작 및 검증

- YunxiNeural 남성 −14 Hz와 XiaoxiaoNeural 여성 −19 Hz를 사용했다. 두 음성 모두 기본 속도 +0%다. 第一部分은 남→여로, 대화는 배역을 유지해 반복한다. 질문, 번호와 안내는 여성 음성이다.
- 번호 뒤 1.7초, 반복 사이 2.35 / 2.45 / 2.55초, 두 번째 낭독 후 풀이시간 13.95초를 삽입했다. 예제 두 번째 낭독 뒤 2.45초, 대화 배역 사이 1.4초, 대화에서 질문까지 1.8초를 둔다.
- 회차 원본에 예제가 없어 각 부분의 예제를 편집했다. 듣기 第二部分은 6–10번의 미사용 B 사진에 맞췄다. 第三部分 16–25번 질문 문장은 회차 원본 문제지에서 그대로 가져왔다.
