작업 폴더: 현재 폴더 (HSK1_재배열)

목표: input\sets 안의 HSK3.0 1급 모의고사 10세트 중 먼저 제01회만, input\참고_HSK3.0_1급_모의고사_2세트.pdf 의 문제집과 똑같은 문제 배치와 배열로 다시 만들고, 참고 파일처럼 예문(각 파트 앞의 例 예시 문항 등, 참고 파일에 있는 방식 그대로)을 넣어라.

단계:
1. 참고 PDF와 input\sets\HSK3.0_1급_제01회_표지통일_전체듣기QR.pdf 를 페이지 이미지로 렌더링해서 직접 보고, 참고 파일의 구조(듣기/독해 파트 순서, 문제 번호, 페이지당 문항 수, 그림과 보기 위치, 例 예문 위치, 표지, 답안지, QR코드)를 정리하라.
2. 제01회의 현재 구조와 차이점을 목록으로 만들어라.
3. 제01회의 문제 내용, 그림, 표지 디자인(표지통일), 듣기 QR코드는 그대로 유지하면서 참고 파일 배열로 재구성하라. 가능하면 원본 페이지에서 잘라 재배치하고, 다시 타이핑해야 하면 한자/병음 오류가 없게 하라. 예문은 참고 파일 스타일을 따르되 제01회 정답과 모순되지 않게 하라.
4. 결과를 output\HSK3.0_1급_제01회_재배열.pdf 로 저장하라. input 폴더의 원본은 절대 수정하거나 삭제하지 마라.
5. 결과 PDF를 다시 렌더링해서 모든 페이지를 확인하고, output\preview 폴더에 표지, 듣기 한 페이지, 독해 한 페이지 PNG를 저장하라.
6. 마지막에 output\report.md 에 한국어로: 참고 파일 구조 요약, 적용한 변경 목록, 예문을 무엇으로 해석했는지, 남은 문제점을 적어라.
