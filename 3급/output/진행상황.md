- 보관 범위는 3급/output과 3급/scripts다. 원본 PDF, 참고음원, TTS 캐시 제외. 최종 미리보기 31장을 눈으로 점검했다. 바탕화면 복사본 2개는 제작본과 SHA-256이 같다.

## 실행

작업 폴더에서 `python scripts/booklet.py --level 3 --set 1`, `python scripts/verify.py --level 3 --set 1`, `python scripts/audio.py --level 3 --set 1 --model <SenseVoice 모델 폴더>`를 실행한다. PDF에는 pymupdf, Pillow, reportlab, pypdf, pypinyin, zxing-cpp가 필요하다. 음원에는 edge-tts, numpy, imageio-ffmpeg, sherpa-onnx가 추가로 필요하다. 새 예제는 scripts/例01.json에 저장되어 있다.

## 제02~04회 최종 대조

- 문제지와 해설 미리보기 총 90쪽을 확인했다. 보관본 및 바탕화면 PDF 6개와 제작본의 내용이 일치한다.
- 3급 원본 10회분의 듣기 대본을 비교했다. 제02회 11번, 제03회 15번, 제04회 13번은 기다리는 사람 이름만 다른 대화다. 제02회 12번, 제03회 16번, 제04회 17번은 단가와 그에 맞는 선택지가 다른 문항이다. 원본 문항과 정답을 그대로 사용했다.
- 듣기 부분마다 13.95초 풀이 무음 10개와 말하기 무음을 최종 MP3에서 검사했다.
- 2026-11-26 GitHub Pages 반영 후 3급 제01~04회 플레이어 주소와 회차당 MP3 5개 모두 HTTP 200 및 배포본과 내용 일치를 확인했다. 1·2급 제01·10회 플레이어 주소도 HTTP 200이다. 플레이어 코드 동작을 기존 60개 급수·회차 조합과 대조했고 3급 제01회와 1·2급 전체 회차의 재생 경로와 버튼 동작이 일치했다.
