## 음원과 배포

- 보관 범위는 3급/output과 3급/scripts다. 원본 PDF, 참고음원, TTS 캐시 제외. 최종 미리보기 31장을 눈으로 점검했다. 바탕화면 복사본 2개는 제작본과 SHA-256이 같다.

## 실행

작업 폴더에서 `python scripts/booklet.py --level 3 --set 1`, `python scripts/verify.py --level 3 --set 1`, `python scripts/audio.py --level 3 --set 1 --model <SenseVoice 모델 폴더>`를 실행한다. PDF에는 pymupdf, Pillow, reportlab, pypdf, pypinyin, zxing-cpp가 필요하다. 음원에는 edge-tts, numpy, imageio-ffmpeg, sherpa-onnx가 추가로 필요하다. 새 예제는 scripts/例01.json에 저장되어 있다.
