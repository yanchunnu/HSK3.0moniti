# HSK 3.0 4급 제01회 견본

- 제01회 원본에서 듣기 32문항, 독해 32문항, 쓰기 6문항, 말하기 5문항과 그림을 추출했다. 객관식 정답 64개는 원본의 빠른 정답표와 문항별 정답을 서로 대조했다.
- 기준 시험지 41쪽을 렌더링했다. 제01회 원본의 듣기 묶음은 1–7, 8–14, 15–20, 21–32번이고, 마지막 묶음은 공통 지문당 두 문항이다. 독해 제2부분은 43–49번 단독 지문, 50–57번 공통 지문당 두 문항이다. 기준 시험지의 대응 범위는 각각 15–19, 20–32번과 43–50, 51–57번이다. 기준 시험지에는 말하기가 없어 원본의 말하기 문항과 시간을 적용했다.
- 듣기 4개, 독해 4개, 쓰기 2개의 새 예제를 사용했다. 새 예문 20개를 기존 시험지 30부의 추출문과 기존 예제 JSON 전체에 대조했다. 쓰기 제1부분 예제에 쓴 자와 리본 그림은 Pillow로 새로 그렸다. 기준 시험지에 병음 표기가 없어 본문에 병음을 사용하지 않았다.
- 문제지 21쪽 462,103바이트, 정답및해설 13쪽 182,976바이트. 최종 미리보기 34쪽을 렌더링해 눈으로 점검했다. 바탕화면에 두 PDF를 복사했다.
- Poppler로 선택지 라벨 240개를 확인했다. 같은 줄의 인접 간격 121개 중 최솟값은 27.011pt였다.
- 두 PDF에서 다른 급수 문자열이 0건이다. 표지 QR 한 개를 디코딩해 플레이어 주소를 확인했다. 문항 번호, 본문, 선택지, 표의 정답, 듣기 원문과 쓰기·말하기 답안을 원본 추출문과 대조했다.
- 플레이어 코드에서 제01회 전체 재생과 세 부분 링크를 확인하고, 나머지 59개 급수·회차 조합의 선택, 버튼, 링크, 종료 동작을 기존 코드와 비교했다.
- 제02~10회 제작은 제01회 확인 후 진행한다.

## 실행

작업 폴더에서 `python scripts/booklet.py --level 4 --set 1`, `python scripts/verify.py --level 4 --set 1`, `python scripts/check_option_gaps4.py --level 4 --set 1`, `python scripts/audio.py --level 4 --set 1 --model <SenseVoice 모델 폴더>`를 실행한다. Poppler `pdftotext`가 PATH에 없는 환경에서는 `PDFTOTEXT`에 실행 파일 경로를 지정한다. Python 의존성은 PyMuPDF, Pillow, ReportLab, zxing-cpp, edge-tts, imageio-ffmpeg, NumPy, sherpa-onnx다.


- 플레이어 `main` 배포 커밋 `af4a1fc5bcb12faf2e9f5f67e181aba97faffe01`. 음원의 실제 길이, 무음 검사, 원문 일치율은 [음원 분석](audio/분석.md)에 기록했다.
- GitHub Pages 반영 후 플레이어 HTML과 MP3 네 개가 모두 HTTP 200이었다. HTML은 줄바꿈을 정규화한 뒤 로컬 파일과 대조했고, MP3 네 개는 SHA-256이 일치했다.
- 바탕화면의 두 PDF와 보관 폴더의 제작 파일을 SHA-256으로 대조했다. 견본 보관 커밋은 `47d3c3f9191f35802334bccbbae420639f3916d9`다.
