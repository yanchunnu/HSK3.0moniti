# 4급 교체 데이터 중복 검사

제01~10회 전체 750문항에서 **정확 중복 0쌍, 근사 중복 1쌍**을 확인했다. 회차 간 중복과 교체 문항이 관련된 중복은 각각 0쌍이다.

남은 근사 쌍은 제01회 듣기 6번과 24번이다. `关于女的可以知道什么`와 `关于基础班可以知道什么`는 정규화 후 각각 10자와 11자로, 10자 미만 제외 규칙에 해당하지 않는다. difflib ratio는 0.7619, 문자 2-gram Jaccard는 0.4615다. 제01회 내용은 수정 금지여서 이 쌍을 그대로 기록했다.

## 검사 기준과 검증

- 같은 회차 내부와 다른 회차 사이를 모두 비교했다. 최종 검사와 동일한 조건에서 원본은 정확 1737쌍, 근사 1497쌍이었다. 두 기준에 모두 걸리면 각각의 집계에 포함한다.
- 문장부호, 공백, 화자·질문·선택지 라벨을 제거하고, 10자 이상 문장의 완전 일치, 문자 2-gram Jaccard ≥ 0.60 또는 difflib ratio ≥ 0.75를 검사했다. 지시문, 머리글, 공통 예제와 10자 미만 문장은 문장 비교에서 제외했다.
- 문항 전체와 공통 지문 묶음은 원문·질문·선택지를 비교했다. 선택지 순서는 정규화했다. 짧은 선택지도 문항 전체 비교에는 포함했다. 문장표·어휘표는 각 묶음에 한 번만 집계했다.
- 객관식 정답 글자 640개를 원본과 대조했다. 교체한 객관식은 지문과 선택지의 근거를 다시 대조했다. 공통 지문과 문장 삽입 문항은 묶음 단위 교체 및 정답 글자 대응을 확인했다. [교체 검토](../tmp/교체검토.md)
- 65–69번 그림·제시어·모범 문장과 74–75번 질문은 원본을 유지했다. 73번 새 이야기는 원본 그림 세 장과 대조했다.
- 제01회 JSON과 원본 추출기의 문항 데이터를 대조했다. 확인용 PDF 두 개는 tmp에만 만들었으며 승인본과 Poppler 추출 텍스트 바이트가 일치했다. 제02~10회는 파일 저장 없이 생성기의 쪽 배치 검사를 통과했다.
- 검사 실행은 작업 폴더에서 `python scripts/dupcheck4.py`를 사용한다. 남은 쌍을 검출하므로 종료 코드는 1이다. 원본은 `--original`로 검사한다. [검사 스크립트](../scripts/dupcheck4.py)
- 회차별 전체 문항, 원본 그림 좌표, 교체 전 내용, 중복 상대 좌표는 [회차별 JSON](../scripts/content4/)에 있다.

- 제01~02회 완성 PDF의 문항 내용과 정답을 확인 후 중복 검사. 교차 중복 0쌍. 제01회 내부 6·24번 근사 1쌍.

- 제01~03회 완성 PDF의 문항 내용과 정답을 확인 후 중복 검사. 교차 중복 0쌍. 제01회 내부 6·24번 근사 1쌍.

- 제01~04회 완성 PDF의 문항 내용과 정답을 확인 후 중복 검사. 교차 중복 0쌍. 제01회 내부 6·24번 근사 1쌍.

완성 PDF와 함께 검사하려면 작업 폴더에서 `python scripts/dupcheck4.py --finished --sets 1 2 3 4`를 실행한다. PDF에서 확인한 문항·정답을 회차 JSON과 대조하고 교차 중복만 종료 코드에 반영한다.
